# Security policy

LumenMorph is a local research application. Its API can start generation jobs
and write to local output paths, so do not expose it to an untrusted network or
the public internet.

To report a security issue privately, use GitHub's private vulnerability
reporting facility for this repository. If it is unavailable, contact
`icirauqui@gmail.com` with the affected version, reproduction steps and impact.
Please do not publish a proof of concept before a fix or coordinated disclosure
plan is available.
